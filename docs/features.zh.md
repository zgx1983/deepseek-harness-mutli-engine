## 个人助理插件：项目看板

当前 `dsh-personal-assistant` 提供只读项目看板，详见[插件说明](../plugins/dsh-personal-assistant/README.zh.md)和[移除旧功能的升级指南](upgrade-guide/v0.2.0-rc.2/personal-assistant-dashboard/guide.zh.md)。

| 功能 | 用途 | 状态 |
|---|---|---|
| 用量看板替代个人助理工作台 | 侧边栏打开项目看板；移除任务、Todo、个人知识、助理对话和常驻协调会话的创建与管理，以及旧模型工具、API、配置和存储路由。已有会话日志与旧数据库文件保留，看板不读取或修改任务数据库。 | 旧功能已废弃、实现已移除；协调构建通过 |
| 今天与近 7 天汇总 | 按浏览器时区显示活跃项目、活跃会话、新建会话和 token 总量；今日图表按小时、七天图表按日期展示。近 7 天包含今天及此前六天。 | 已实现；构建通过，用户已确认看板加载可用 |
| 项目与会话用量明细 | 按 Workspace 登记并核对会话工作目录归属项目，未匹配的会话列入未归属项目；显示项目用量和最近活动会话明细，界面最多展示 30 条会话。 | 已实现；完整统计对账待验收 |
| Native、Codex、Claude token 统计 | 累加会话日志内提供方报告的输入、输出、缓存读取和缓存写入；补计单条总量及 Codex/Claude 引擎累计总量中未被分项覆盖的差额，排除 fork 继承事件，避免重复计数。 | 已实现；协调构建通过，真实三引擎用量对账待验收 |
| 万、亿单位显示 | 中文大数保留两位小数，例如 `1.00万`、`1.00亿`；总量、图表和明细使用同一格式。 | 已完成：数字格式验证与构建通过 |
| 缓存、刷新与加载反馈 | 从 `sessionQuery` 读取会话、从 `workspaceRegistry` 读取项目；快照缓存一分钟，手动刷新重新计算。加载失败显示诊断码，可重试；读取失败的会话显示不完整统计提示。历史日志缓存减少重复解析，但首次统计仍需扫描历史。 | 已实现；用户已确认加载可用，大规模历史耗时待测量 |

活跃会话指统计周期内有用户或模型消息的会话，不等同于后台正在运行的 Agent。统计仅覆盖应用可读取的会话日志：提供方未报告的用量、应用外未导入的引擎会话和读取失败的会话无法补齐；引擎累计差额计入报告时刻。

## 会话归档与项目历史

| 功能 | 用途 | 状态 |
|---|---|---|
| 归档时选择是否总结 | 确认框默认不勾选总结；普通归档不调用模型，项目会话可选择写入总结。已有运行任务仍需停止确认。 | 已实现；归档选项与普通归档已有录制会话回放验证 |
| 原引擎、原会话直接写入 changelog | 用原 Native、Codex 或 Claude 引擎提交一次总结 follow-up，明确所属项目根目录 `CHANGELOG.md` 的绝对路径；引擎使用自身工具保留原内容，追加带时间及会话 id 的简短条目。请求、工具操作、回复与 token 用量留在原会话日志中。 | 已实现；类型检查和协调构建通过，真实引擎验收待完成 |
| 后台静默总结 | 勾选总结并确认后立即关闭弹窗，后台生成、检查并归档，成功时不提示；失败显示通知，保持未归档，引擎已执行的文件改动保留。 | 已实现；构建通过，实际交互验收待完成 |
| 总结结束后的归档提交保护 | 等待总结轮次进入空闲，在 Agent 维护阶段内刷盘、只读确认条目并提交归档，期间暂缓新轮次启动；排队消息拒绝归档，其他提供方的活动仍要求停止确认。同一会话的并发请求共用一次操作。 | 已实现；2026-10-11 类型检查和协调构建通过，实际归档流程待验收 |
